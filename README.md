# 🧠 Truth Table Project

## 🎯 Goal

Understand how logical expressions work by checking all possible cases using code.

---

## 🧩 Problem

Evaluate the logical expression:

\[
(A \lor B) \land (\neg A \lor B)
\]

We want to check:

👉 For which values of A and B is this expression TRUE or FALSE?

---

## 💡 Approach

Instead of manually creating a truth table, we use code to:

1. Try all combinations of A and B  
2. Evaluate the expression  
3. Print the result  

---

## 🔁 All Possible Cases

| A | B |
|--|--|
| True | True |
| True | False |
| False | True |
| False | False |

---

## 🧠 Key Insight

- `OR (∨)` → true if at least one is true  
- `AND (∧)` → true only if both are true  
- `NOT (¬)` → reverses value  

---

## 🎯 What This Teaches

- Logical thinking used in programming  
- How conditions are evaluated in code  
- How to test all cases (important for debugging)

---

## 🚀 Application in Computer Science

- Writing `if` conditions  
- Debugging logical errors  
- Designing algorithms  
- Digital circuits  

---

## 📌 Takeaway

> Instead of guessing logic, always test all possibilities.
